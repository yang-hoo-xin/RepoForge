# Triage Labels

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | Reporter information is required |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Human implementation or judgement is required |
| `wontfix` | `wontfix` | The request will not be actioned |

When a skill names a triage role, use the corresponding GitHub label exactly.
