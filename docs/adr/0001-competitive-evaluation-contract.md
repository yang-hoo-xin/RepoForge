# Use a frozen three-group contract for competitive evaluation

RepoForge will evaluate a mature coding backend (A), the Task Agent without Strategy Experience (B), and the same Task Agent with one frozen Strategy Experience version (B+) on pre-registered C#/.NET tasks. Correct delivery requires independent acceptance and a source-bound usable artifact; task-specific rescue, mid-batch version changes, evaluation-task experience leakage and post-result task removal are excluded. This separates backend-route evidence from experience gain while preserving failures, costs, negative transfer and repository-level holdout results.

## Consequences

The formal milestone targets 10 repositories and 120 independent tasks, with a smaller 12-task pilot and a separate stability appendix. A changed model, tool contract, permission policy, runtime image or evaluator starts a new evaluation version; completing the benchmark remains a product-evidence milestone rather than completion of the full RepoForge goal.
